- **Sensores y microcontroladores** ([Sensores-Teoria](https://github.com/Dathinel/Sensores-Teoria)): ESP32 con MicroPython y C++, Python con OpenCV, PyTorch, TensorFlow y Streamlit, laboratorios Docker con MQTT.
