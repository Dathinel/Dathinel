# Dathinel

Soy estudiante y hago programas para cosas que uso: editar un video, subtitular una conversación o pasar una carpeta de un equipo a otro. Aprendo construyéndolos, con ayuda de la IA, y publico el código para que se pueda probar y modificar.

[Ver mis repositorios por actividad](https://github.com/Dathinel?tab=repositories&type=source&sort=updated)

## Video, audio y subtítulos

Uso **Rodaje** para editar por capas, mezclar audio y exportar el video. Si solo necesito sacar los subtítulos o seguir un objeto en movimiento, puedo abrir una herramienta más pequeña y procesar el material en mi propio equipo.

[Editor Rodaje](https://github.com/Dathinel/rodaje) · [Subtitular](https://github.com/Dathinel/subtitular) · [Rastrear](https://github.com/Dathinel/rastrear) · [Catálogo de complementos](https://github.com/Dathinel/rodaje-catalogo)

## De un equipo a otro

Con **BeamLine** puedo enviar archivos y carpetas entre Windows y Linux. Los equipos de la misma red aparecen solos y, para enviar algo por internet, comparto un ticket. **Sala** resuelve otro problema: varias personas editan su propia copia de un proyecto y el anfitrión reúne los cambios.

[BeamLine](https://github.com/Dathinel/beamline) · [Sala](https://github.com/Dathinel/sala)
